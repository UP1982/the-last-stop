# Pixel art, animation, and audio guide

## Style
Original, small scale, soft dreamy colors, 16×16/32×32 tile units, 320×180 logical stage. Readability over intricate textures. Nearest-neighbor filtering; avoid HD vector UI mixed inconsistently into pixel art. Stations are framed like storybook vignettes, routes show scrolling layered environments.

## Palette
Midnight `#1C243B`, Twilight `#34476A`, Lavender `#766793`, Lamplight `#E8B96E`, Moonmint `#A9D1BB`, Cream `#F2DCCA`. Additional tones only as needed for contrast.

## Asset production order
1. Colored rectangle prototypes for train, cat, branch, winch, handle, shed and interact prompts.
2. Milo idle/walk/jump, 4–6 frames per main action if feasible; paws and tail more important than complex sprites.
3. Train silhouette, door, wheel loop, windows, station sign.
4. Oliver sprite and close-up dialogue portrait, rain, umbrella, flowerpot.
5. Puzzle animation (winch turning, rope tightening, branch rolling), tiny snail.
6. Background layered sky, hill, trees, distant tracks, two station cutscene backdrops.
7. Clean font and minimal UI, gentle colorblind-readable interactions.

## Audio priorities
One short gentle music loop, one scenic transition bed, ambient rain/forest, train idle/wheels/whistle, steps, pickup, winch creak, branch moving, dialogue ticks. Sparse and low-volume. Add silent mode and separate master/music/SFX controls later.

## Licensing
Maintain `assets/ASSET_LICENSES.md` with asset name, creator, source, license, modifications. No game assets have been provided in this starter kit. Do not scrape or imitate copyrighted CAT & ONION art/audio.
